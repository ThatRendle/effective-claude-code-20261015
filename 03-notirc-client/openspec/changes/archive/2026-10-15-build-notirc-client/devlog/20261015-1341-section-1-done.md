Decisions and gotchas:
- **Test project is hand-written.** The xUnit v3 `dotnet new` template isn't installed, and installing it would add a tool outside `docs/dependencies.md`. Packages `xunit.v3` and `xunit.v3.mtp-v2` 4.0.2 and `Avalonia.Headless.XUnit` 12.0.4 were added with `dotnet add package`. Headless is pinned to 12.0.4 to match the app. The latest, 12.1.4, would force a version-downgrade error. `Microsoft.NET.Test.Sdk` was not added, because MTP doesn't need it.
- **`dotnet test --solution` needs `"test": {"runner": "Microsoft.Testing.Platform"}` in `global.json`.** Without it: `MSB1001: Unknown switch`. The gate command is unchanged. design.md's gate note is updated.
- **SDK pin.** `global.json` pins 10.0.100 with `latestFeature`, so `dotnet --version` prints 10.0.400. The 11 RC is not picked.
- **Shared build props live in `Directory.Build.props`.** It sets net10.0, nullable, implicit usings, `EnforceCodeStyleInBuild` and `AnalysisLevel latest-recommended`. The csproj files no longer repeat them.
- **Analyzer fixes.** `Program` is now `internal sealed` (CA1852). CA1707 (underscores in names) is silenced for `NotIrc.Tests/**.cs` only, so tests can use `Does_x_when_y` names.
- **Template files were reformatted once.** The Avalonia template ships CRLF and a BOM, which `.editorconfig` (lf, utf-8) rejects. I ran a single `dotnet format NotIrc.slnx` rewrite to normalise them. The `make format` gate stays a check only.
- **Sandbox.** `make deps` reported gh unauthenticated when sandboxed and passed unsandboxed. All dotnet and git commands needed the sandbox off (NuGet, `.git` writes).

Proofs: the test gate exits non-zero on a deliberately failing test (`TEST_EXIT:2`). The format gate reports `WHITESPACE` errors on a deliberately misformatted file. That run's exit line was cut off by `head`, but the same gate gave `FORMAT_EXIT:2` earlier on the unnormalised scaffold.

Self-review: found duplicated properties in the csproj files and removed them. There is no dead or stub code. Nothing in §1 touches the specs.
